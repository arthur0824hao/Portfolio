# bh-engine

bh-engine 銜接任務排程與可用的工具，使工作要求能交給相應的執行環境。讀取工具名單可以回答「登記了哪些能力」；要判斷某次工作有沒有達成目的，還要核對那次執行的結果。

## 小圖

```text
工作要求
  ↓
bh-engine 排程、呼叫工具
  ↓
執行結果
  ├─ 證據可對應 → 回報觀察結果
  └─ 回覆不完整 → 待核對原紀錄
```

## 相接部位

Nerve 可依 bh-engine 回報的工具清單整理能力登記，Workbench 可呈現工作狀態。若回覆中斷，工作要求可能已經生效。保留「效果未知」讓接手者先核對原紀錄，避免把同一要求做兩次。

## 數字與限制

**59 個相異的工具名稱。** 這是 2026 年 11 月 22 日一次登記快照的觀察值。量法是計算清單筆數，再按名稱去重，兩者都是 59。範圍限於當日清單；逐項能否成功執行、執行速度與服務可用率都需要另外量測。
