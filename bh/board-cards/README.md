# 看板與卡片

卡片保存一件待辦的問題、責任與決定，看板依狀態把卡放到讀者面前。要判斷兩張標題相似的卡是否重複，可以先看它們各在等待什麼：一張可能等人審閱摘要，另一張則持續追蹤摘要內待解的問題。

## 小圖

```text
工作規劃中的待辦
  ↓
卡片記下問題與依據
  ↓
看板呈現待接手狀態
  ├─ 待補件 → 留下缺口
  └─ 已驗收 → 留下決定與依據
```

## 相接部位

工作規劃中的一項待辦可以對到一張卡，Workbench 呈現卡片，Panel 摘要待處理狀態。建立卡片和後續由人接手是兩個可以各自核對的事件。

## 數字與限制

**1 張待接手的卡片。** 在一次舊待辦轉接回件中，逐項檢查是否有目的卡記錄、已建立且處於待接手狀態，符合條件的有 1 張。回件也記下原待辦仍保留。這只量到該次建卡；接手耗時與最終是否結案，要看後續卡片歷程。
