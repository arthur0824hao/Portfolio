# Workbench

Workbench 把工作進度、檢查結果和待決事項放在同一個工作畫面。讀者能順著一項工作看見它已經走到哪一步，以及接下來需要誰判斷。交件之後，畫面仍應讓審閱者辨認是否已有驗收結果。

## 小圖

```text
工作資訊
  ├─ Weaver 的工作進度
  ├─ Panel 的檢查結果
  └─ 看板上的待辦
        ↓ 彙整
     Workbench
        ↓
人檢視依據、處理待決事項
```

## 相接部位

Weaver 提供工作狀態，Panel 提供檢查的判讀，看板與卡片保存人的問題和決定。這些記錄各有用途：能看到一份交件時，仍需從對應回條確認審閱結果。

## 數字與限制

目前沒有可公開的量測

已有的介面檢查採用合成名冊，只觀察畫面排版和選取狀態。它沒有量到真實工作中的等待時間、寫回結果或服務可用率。
